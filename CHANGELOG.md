# Changelog

## v0.1.0-rc1 - 2026-09-20

First Windows Release Candidate.

### Added

- Patent number normalization for CN / JP / EP / US / WO / KR.
- Company ownership entity graph and historical applicant expansion.
- EPO OPS search, publication lookup and patent-family retrieval.
- JP domestic API adapter foundations.
- Multilingual suspension technology dictionary.
- Whole-family PDF download center with source fallback and manifests.
- Incremental Patent Watch with SQLite state and scheduler.
- Local patent library with tags, projects, favorites, notes and exports.
- Tkinter desktop application with Search, Family, Watch, Library and Settings.
- Windows Credential Manager integration for EPO OPS credentials.
- Automated Windows one-file EXE build, smoke testing and release packaging.
