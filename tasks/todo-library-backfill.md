# 覆盖率检查与确认后补库任务清单

- [ ] 覆盖率服务（外部总数、本地命中、日期完整度）。
  - 验收：比例正确；数据源不给总数时显示"未知"，不估算。
  - 验证：假数据源测试。
- [ ] 补库任务（去重、上限、取消、逐件失败、来源记录、任务 JSON）。
  - 验收：默认上限 200；已在本地的公开号跳过；每件带 `BACKFILL` 来源。
  - 验证：假数据源 + 假下载器测试。
- [ ] 智能体与情报分析页接入"建议补库"和确认框。
  - 验收：覆盖率低时提示；确认后才联网；补库报告可查看。
  - 验证：桌面测试。
- [ ] 设置项：上限与阈值。
  - 验收：上限 1–1000，默认 200；阈值可调。
  - 验证：设置测试。
- [ ] 真实库人工验收。
  - 验收：补库后重跑同一问题，引用增多、覆盖说明更新。
  - 验证：人工核对。
