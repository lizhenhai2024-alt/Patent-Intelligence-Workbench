# 覆盖率检查与确认后补库实施计划

前提：全文索引（`tasks/SPEC-fulltext-index.md`）已完成。

1. 覆盖率服务：同一检索式的外部总数与本地命中数、日期完整度。
   - 检查点：假数据源测试（含"总数未知"）。
2. 补库任务：检索 → 去重 → 入库 → 专利族 → 下载 → 著录补全 → 全文索引；上限、取消、逐件失败处理；`BACKFILL` 来源和任务 JSON。
   - 检查点：假数据源 + 假下载器测试。
3. 智能体与情报分析接入：结果顶部显示覆盖率和"建议补库"；确认框（复用检索词确认对话框）。
   - 检查点：桌面测试；未入库公开号仍被标红。
4. 设置：默认上限 200（硬上限 1000）、覆盖率与日期缺失阈值。
   - 检查点：设置保存测试。
5. 人工验收：真实库上对"复原弹簧""KYB CDC 阀"做覆盖率检查和补库，重跑问题对比结论。

## 边界

- 始终：用户确认后才联网；复用现有检索/下载/入库代码；不新增依赖。
- 需要时再问：定时自动补库；新数据源。
- 绝不：智能体直接调用联网工具；推断日期写库。
