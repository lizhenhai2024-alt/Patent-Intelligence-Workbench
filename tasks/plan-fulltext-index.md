# 本地专利全文索引实施计划

1. 新增三张表（`library_text_source`、`library_text_segment`、`library_text_fts`）和 trigram 可用性检测。
   - 检查点：旧数据库打开后自动建表，不影响现有数据；只读连接能查询。
2. `app/library/fulltext.py`：PDF 分段解析（章节、权利要求号、段落号、页码）、状态判定、增量（SHA-256）。
   - 检查点：解析与增量测试通过。
3. 同步集成：在本地库同步/补全后执行全文索引；EPO OPS 补齐缺失文本并标来源。
   - 检查点：补齐测试通过；提供者报错不中断同步。
4. 检索：trigram 检索、短词 LIKE 回退、`all`/`any`、片段与位置。
   - 检查点：检索测试通过（含"复原弹簧"正文命中）。
5. 工具升级：`search_library`、`read_publication_text`、`library_status`；更新 `library_qa.md` 步骤。
   - 检查点：M1 工具测试全部通过，数据库哈希不变。
6. 桌面：本地专利库页"更新全文索引"按钮、进度、取消。
   - 检查点：桌面测试；在真实库上首次建索引，按验收标准重问"复原弹簧"。

## 边界

- 始终：只新增；不新增依赖；同步阶段才联网。
- 需要时再问：OCR；语义检索。
- 绝不：智能体运行时联网；用模型补文本。
